2.2 실시간 하버사인 거리 계산 인터랙티브 시뮬레이터

0.01초 순수 JS 연산

지구의 곡률을 반영한 Haversine 공식을 사용해 내 GPS 좌표와 스쿨존 좌표 간의 정확한 직관 거리(m)를 즉각 산출합니다.

기본값: 서울 강남 대곡초 부근
보호구역 지정 좌표
계산된 직선 거리
25.7 m
경고: 300m 보호구역 내 위치!
getDistance(lat1, lon1, lat2, lon2) Pure JS 
function getDistance(lat1, lon1, lat2, lon2) {
  const R = 6371e3; // 지구 반지름 (m)
  const rad = Math.PI / 180;
  const dLat = (lat2 - lat1) * rad;
  const dLon = (lon2 - lon1) * rad;
  const a = Math.sin(dLat / 2) * Math.sin(dLat / 2) +
            Math.cos(lat1 * rad) * Math.cos(lat2 * rad) *
            Math.sin(dLon / 2) * Math.sin(dLon / 2);
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
}

팝업 + TTS + 진동 / 안심 링크

F-1

보행자 실시간 3중 알림

어린이 및 시니어 보행자가 스쿨존 300m 이내에 들어서면 시각, 청각, 촉각 3가지 신호로 즉각 경고합니다.

  • HTML/CSS 대형 모달: 대형 고대비 경고 배너
  • 음성 TTS API: speechSynthesis 사용
  • 스마트폰 진동 API: vibrate([200, 100, 200])
F-2

부모 안심 1-Click 알림

복잡한 백엔드 푸시 서버 없이, 아이가 학교 근처에 도착 시 활성화되는 카카오톡/SMS 원클릭 전송 기능입니다.

"OO이가 OO초등학교 보호구역에 무사히 도착했습니다! 현재위치: https://maps.google.com/..."
F-3

Leaflet.js 무료 지도 마커

유료 키 발급 부담이 없는 오픈소스 Leaflet.js & OpenStreetMap을 사용하여 현재 위치와 주변 스쿨존을 지도 상에 직관적으로 시각화합니다.

API 키 불필요 정적 웹 호스팅 최적화
